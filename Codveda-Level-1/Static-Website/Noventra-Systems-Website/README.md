# Noventra Systems — Static Website

A six-page responsive IT company website concept built with HTML, CSS and vanilla JavaScript.

## Pages
- `index.html` — Home
- `about.html` — About
- `services.html` — Services
- `projects.html` — Illustrative project concepts
- `insights.html` — Educational articles
- `contact.html` — Front-end demo contact form

## Run locally
Open `index.html` in a browser, or use the VS Code Live Server extension.

## Notes
- The Noventra Systems brand and portfolio content are fictional and intended for an educational project.
- The contact form is front-end only. It does not send or store messages.
- Google Fonts are loaded from Google Fonts; the site otherwise uses local HTML, CSS and JavaScript.
- The logo mark is recreated with text/CSS as a lightweight placeholder. Replace `.brand-mark` with your transparent `images/logo.png` if desired.
